# 九艺创作助手

为 CG 美术设计师做的**创作迭代记录与复盘工具**。把作品的每一版都留在原地，
回头能看清自己是怎么一步步改过来的。

**作者**：B站-鸣沙大叔

## 下载

到 [Releases](https://github.com/Mingshaaaaaaaaaa/jiuyi-creation-assistant/releases/latest) 页面下载最新的
`JiuyiCreationAssistant-<版本号>.exe`。

单文件绿色版，**不需要安装**，双击就能跑。

## 关于更新

软件内置在线更新：装好之后新版本发布会自动提示，可以直接在软件里一键升级，
不必再回来这里手动下载。

> 这个仓库只放**发布件与更新清单**，不提供源代码。
> `latest.json` 是客户端用来判断有没有新版本的清单文件，**请勿手动修改**——
> 改了它，所有用户的更新提示都会跟着错。

## 你的数据在哪

所有项目、原图、缩略图、复盘文字都保存在你自己电脑的
`文档/JiuyiCreationAssistant` 文件夹里，**完全本地**，不上传任何东西。
备份就是复制这个文件夹，换电脑就是把它拷过去。
